# Искра и Капля — Храм равновесия

Оригинальный браузерный платформер с головоломками для двух игроков за одной клавиатурой. HTML, CSS, JavaScript и JSON; без библиотек, установки и сборки.

## Запуск

Откройте `index.html` в современном браузере. Все файлы должны оставаться в одной папке. Также можно запустить `python -m http.server 8080` в папке проекта и открыть `http://localhost:8080`.

## Управление

| Действие | Искра | Капля |
| --- | --- | --- |
| Движение | A / D | ← / → |
| Прыжок | W | ↑ |
| Использовать рычаг | E | ↓ |
| Перезапуск | R | R |
| Пауза | Escape | Escape |

Управление работает по физическим клавишам, в том числе при русской раскладке. Для игры требуется клавиатура; сенсорное управление в проект не включено. Одновременные нажатия обрабатываются независимо. Некоторые клавиатуры аппаратно ограничивают сочетания нескольких клавиш (ghosting).

## Правила

- Искра проходит через огонь, Капля — через воду. Чужая стихия и зелёный туман опасны.
- Обоим нужно одновременно дойти до порталов своего цвета. Столкновений между персонажами нет: они не мешают друг другу.
- Обычные плиты фиксируют активацию. Парные плиты требуют одновременного присутствия двух персонажей, затем фиксируют активацию.
- Квадратную плиту включает только ящик, который нужно толкать сбоку.
- Цветные плиты и рычаги доступны только соответствующему персонажу.
- Временные рычаги открывают проход на 12 секунд. Включайте их повторно после отпускания кнопки действия. Ворота не закрываются поверх персонажа.
- Подъёмник переносит стоящего на нём игрока автоматически.
- Кристаллы необязательны: собирайте только кристаллы своей стихии. Все кристаллы дают 3 звезды, прохождение быстрее 90 секунд — 2, остальные прохождения — 1.
- Гибель одного персонажа завершает попытку обоих. Количество попыток не ограничено.
- Все уровни доступны сразу. Рекорды и звёзды сохраняются в localStorage этого браузера. Звук включается кнопкой в шапке.

## Десять уровней

1. Первый свет — обучение прыжкам и порталам.
2. Две стихии — бассейны и опасный туман.
3. Следы на камне — плита и запирающий проход.
4. Забытый механизм — два рычага на разных уступах.
5. Вес решения — ящик и плита веса.
6. Подъём в тишине — высокий уступ с движущейся платформой.
7. В одном ритме — одновременные цветные плиты.
8. Двенадцать секунд — рычаг и маршрут на время.
9. Три ключа — ящик и два персональных рычага.
10. Сердце равновесия — ящик, совместная активация и последние временные ворота.

## Файлы

- `index.html`, `style.css` — интерфейс и оформление.
- `engine.js` — физика, столкновения, механизмы, условия победы.
- `game.js` — ввод, графика Canvas, меню, звук, рекорды.
- `levels.json` — данные всех уровней.
- `levels.js` — браузерная копия данных, чтобы игра запускалась и через `file://` без fetch.
- `build_levels.py` — создание JSON и JS из описаний уровней. После редактирования генератора выполните `python build_levels.py`. Если редактируете `levels.json` напрямую, обновите `levels.js`: `window.LEVEL_DATA = <значение массива levels>;`.
- `test-engine.cjs` — автоматические проверки движка; запуск `node test-engine.cjs`.
- `.github/workflows/pages.yml` — публикация через GitHub Actions.

## GitHub Pages

1. Создайте новый публичный репозиторий `ember-tide`.
2. Загрузите в ветку `main` **содержимое** папки проекта, включая `.github/workflows/pages.yml`. `index.html` должен находиться в корне репозитория.
3. Откройте Settings → Pages → Build and deployment → Source → **GitHub Actions**.
4. В Actions запустите workflow **Deploy game to GitHub Pages** (Run workflow), если он ещё не запущен автоматически.
5. Адрес после успешного развёртывания: `https://<ваш-логин>.github.io/ember-tide/`.

Workflow устанавливает необходимые права для публикации. При необходимости подтвердите разрешение выполнения Actions в настройках репозитория.

## Проверка

Автоматические проверки покрывают количество и различие уровней, безопасные начальные позиции, опоры плит и порталов, независимый ввод двух игроков, стихийные опасности, толкание ящика, совместные плиты, таймеры, ограничения цвета, выходы и перенос подъёмником. Код не загружает внешние ресурсы и не требует сетевого доступа во время игры.
